# Caos no Cruzamento

Caos no Cruzamento é um jogo que fizemos para a disciplina de PIF desenvolvido em C utilizando a biblioteca Raylib que simula o movimento de veículos em um cruzamento. O objetivo é lidar com o trânsito e evitar que aconteçam colisões e congestionamentos, tornando a experiência um desafio de atenção.

Grupo: Beatriz Vieira, Bryan Martins, Ana Júlia de Melo

## Como compilar

Para compilar o jogo, utilize o comando:

gcc main.c mapa.c objetos.c -o jogo -lraylib

Depois execute:

./jogo
